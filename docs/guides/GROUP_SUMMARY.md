# 群聊自然语言总结 V1

## 用法
白名单群内任意群友真实 @机器人后发送：
- 总结一下贝爷今天的发言。
- 总结一下今天群里都聊了什么。
- 回顾昨天群里关于显卡的讨论。
- 汇总近三天的聊天记录。

不需要真实艾特总结对象；按群名片/昵称精确匹配，唯一的包含匹配也可，重名或未命中会要求完整昵称或真实@目标。不同QQ同名不合并；当前名片和本群近三天已取得记录中的名字都参与匹配。
支持一次一位群友或全群；没指定人物就是全群。默认北京时间今天零点到请求时刻，昨天为昨天全天；最多允许当前前72小时内，超过则请缩小，不静默改范围。主题由自然语言提取，不把话题当人名。

## 历史与边界
- 白名单当前群原始消息实时存SQLite，消息正文最多4000字，滚动72小时，每群最多30000条。仅群聊，不读取私聊或其他群。不保存机器人自己的总结输出。
- 查询时尝试get_group_msg_history向前分页，每页100，最多20页/约30秒的分页预算（单次请求另有5秒超时）；并与本地记录去重合并。
- 平台返回历史不全、入群前记录不可见、活跃群容量不足都可能无法覆盖完整三天；回执显示请求范围、可见记录时间/数量及局限，不把查不到当作没人发言。
- 单次选最新最多1200条/正文约60000字；超限明确标部分记录。分段模型总结后合并，不把截断当完整记录。
- 图片、语音、文件、转发只保存占位不展开，不OCR/转写。纯文本聊天中的观点不被当事实或交易指令。
- 撤回实时删除正文并留72小时防回填墓碑；总结过程中有撤回则请新请求。已经发出去的摘要不自动撤回。平台未通知的旧撤回仍取决于平台返回。

## 权限与运维
配置groupSummary.enabled默认false，生产已true。仅当前白名单群真实@机器人触发；检查拒绝名单、会话模式及暂停/静默。不同群身份/历史不混用，模型不接收QQ号，只接收昵称和文本。
独立调用既有DeepSeek官方凭据/模型，不新增MCP/API，不受普通聊天唤醒限频/潜水队列等待；不发起管理操作。
每群同时一个请求，每人每群每小时3次、每群12次。请求ID防重；发送前记录sending，重启或不明结果不自动重发，新指令才能重试。
数据state/group-summary/history.sqlite3，目录700/文件600；每小时逻辑清理72小时前消息/请求，撤回墓碑也清理。WAL、文件系统残留不等于安全擦除；未添加外部备份或长期档案服务。
原角色卡、记备忘等既有功能不变；仅重启桥接，不升级SDK或重启DSH/QQ。
测试node --test scripts/test-group-summary.mjs；13项离线测试及相关回归通过。真实模型解析及合成资料总结、QQ历史接口只读分页烟测通过；真实QQ入口待群内使用验收，本轮未主动发群消息。

接口依据 https://snowluma.github.io/zh/docs/api/extended/get_group_msg_history ，同时核对当前容器/app/runtime/index.mjs参数message_id/count/reverse_order。

## 口语触发修复
已支持“今天群里说了些啥／今天大家聊了些什么／贝爷今天讲了哪些事”等组合表达，统一走专用总结流程。今天/昨天/前天、近三天及无时间默认今天的简单范围由后端固定北京时间，具体日期/子时段仍解析后校验。18项测试通过，未主动发送QQ群验收消息。

## 短纯文本与精简（2026-11-06已上线）
默认不再把模型Markdown直接发送，最终JSON重点由后端固定渲染为短纯文本：对象/请求时段/可见条数+最多4条重点+单行短注。单条最多100字、正文合计250字，通常2～4条，少信息不凑字。
重点保留主要话题、重要数字时间、更正、结论及实际待办，合并重复寒暄，不输出贬低评价。不完整记录显示实际可见时段，超限/截断/仅文字等限制仍留短注。
复用已有Markdown转纯文本工具做兜底；格式或长度异常最多一次修复，不强行截断重要价格和日期。本版不做图片/Ark卡片。23项总结测试及相关回归通过，真实模型合成资料精简烟测通过，QQ群效果请发送新总结请求查看，旧回复不自动重发。
