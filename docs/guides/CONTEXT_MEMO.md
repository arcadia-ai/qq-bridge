# 上下文备忘 V2

白名单群真实 @机器人后发送“记一下”“记一下麻烦你了宝”“记住上面”等，或主人私聊同样发送。
只从当前会话、同一真实QQ最近20分钟/最近50条候选中取最多20条资料，全文最多12000字。
新入站保留短期完整文本；旧缓存按真实消息ID向QQ读取并校验作者/群/原消息时间，拒绝转发/图片或不完整资料。不跨群，不按昵称匹配。

明确正文、指定时间、批量补记沿用原逻辑，不被模型改写。上下文提取独立调用现有DeepSeek账户与deepseek-flash，不经过普通聊天的唤醒/潜水队列。
唯一明确事项自动写原SQLite，返回完整摘要和M编号。多个事项/矛盾时先给草稿：同一作者在同一会话5分钟内 @机器人“备忘 确认 C-编号”。未确认不入备忘列表。
每次固定指令之前的候选快照，保留来源ID、证据、原消息时间在context_memo_requests表；数字须有对应原文证据，7w7可规范化为77000，缺入场价不从盈亏比反推。

交易计划未提供入场价时：仅对原文明确的完整币安永续合约代码（如BTCUSDT/BTCUSD_PERP）查询对应合约记录时点前1秒内聚合成交参考价。
只调用公开exchangeInfo/aggTrades，验证永续合约和时间，不访问账户、不用币安Key、不执行交易；不拿当前价格或下一分钟收盘价代替历史价。
接口不可达、品种/本位不明确、无时点数据或响应截断时一律记“入场：市价”，固定记录时间留待回溯。大饼等简称不擅自选USDT/币本位。

可用“@机器人 备忘 回溯 M-编号”重查对应历史价；仅创建者/主人修改，保持原记录时间，有修订历史。简称需要先用现有“备忘 修改 M-编号 完整正文”补充合约代码后回溯。
查不到继续保留市价，不自动遍历旧备忘、不重写历史记录。明确正文直存的条目本版不自动添加行情。

同会话一个提取任务、每作者每群每小时最多12次；无完整历史、模型超时/提取失败时询问补正文，不把客套话当正文保存。
独立持久请求表随原memos.sqlite3一起备份；重启不续跑提取，已写入依原operations防重，原始指令中断需新发。
配置 memo.contextEnabled 默认false，生产true；仅重启桥接，无新MCP写权限/外部服务或角色卡改动。
测试 node --test scripts/test-context-memo.mjs。
